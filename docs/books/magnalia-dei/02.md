# 第二章　认识神

神是人至高的善——这是整本圣经的见证。

圣经以这样的记述开篇：神照着自己的形象与样式造了人，为要叫人正确地认识神他的创造者，衷心地爱他，并与他一同活在永远的福乐里。而圣经以对新耶路撒冷的描绘结束：那城的居民要见神的面，他的名字要写在他们的额上。

在这一头一尾之间，横亘着神的启示，其长阔无边。这启示以恩典之约那独一、宏大、涵盖一切的应许为其内容——"我要作你们的神，你们要作我的子民"——并在那"以马内利，神与我们同在"里得着它的中枢与顶峰。因为应许与成全是携手并行的；神的话语是那作为的开端、种子与萌芽，并在那作为中臻于完全的实现。正如神在起初藉着话语把万物从无中呼召到有；照样，他也藉着应许的话语，在诸世代的进程中，成就那新天新地，就是神的帐幕要在人间的所在。

因此，那位道成肉身的基督，在约翰笔下（约1:14）也被称为充充满满地有恩典有真理。

他就是那道，在起初与神同在，自己也是神，并且如此就是人的生命与光。因父在他里面分赐自己的生命，在他里面说出自己的意念，所以神完全的本质在他里面显明出来。他不单向我们讲明父、向我们启示父的名，更在他自己里面把父指给我们看、把父赐给我们。基督是被说出的神，也是被赐下的神；是启示自己的神，也是分赐自己的神，因此充满真理，也充满恩典。那应许的话——"我要作你们的神"——从被说出的第一刻起，就把成全包含在自身之内：我是你们的神。神把自己赐给他的子民，为要叫他的子民把自己献给他。

在圣经里，从神一方，我们看见那一再重复的宣告：我是你们的神。从创世记三章15节那"母亲的应许"起，在列祖生平的每一刻、在以色列民的历史里、在新约教会里，这满含一切救恩的丰富应许被反复申明。而与之相应的，是历世历代从教会一方，以无穷的变奏所发出的、信心那感恩与夸胜的言语：你是我们的神，我们是你的子民，是你草场的羊。

这宣告不是一条理性的教条，也不是照本宣科、彼此附和的一纸信条，乃是对一种深深感受到的、在生命本身中亲历过的实在的告白。众先知与众使徒，以及一般而言那些在新旧约里、后来在基督教会里出现在我们面前的敬虔人，并没有用抽象的概念对神作哲学的思辨，而是告白了神对他们是什么、他们在人生一切境遇中在他们的神里面拥有什么。神对他们不是一个供他们理智剖析的冷概念，乃是一位又活又有位格的大能，一种实在，其真确远远超过他们周遭的世界，就是那独一、永恒、可敬拜的存有。他们在生活中与他打交道，他们住在他的帐幕里，他们行在他的面前，他们在他的院宇中供职，他们在他的圣所里敬拜。

他们经历的真挚与深邃，显在他们用来表达神对他们是什么的言语上。他们无需搜寻词句，因为心里所充满的，口里就满溢出来，而人的世界与自然界为他们的思想提供了图象。神对他们是君王，是主，是勇士，是引路者，是牧人，是救主，是拯救者，是救赎主，是搭救者，是医治者，是丈夫，是父亲。他们一切的拯救与福乐、真理与公义、生命与慈爱、能力与刚强、平安与安息，都在他里面寻见。他是他们的日头与盾牌，是圆盾与挡牌，是光与火，是泉源与活水的源头，是磐石与避难所，是高台与保障，是赏赐与荫庇，是城邑与圣殿。世上分散、零星所含的一切美物，都不过是那存于神里面、为他子民预备的、追寻不尽之救恩丰盛的一个写照。因此大卫在诗篇十六篇2节（按较佳的译法）如此对耶和华说：你是我的主，我没有比你更高的好处（你是我至高的善）；亚萨在第七十三篇里歌唱说：除你以外，在天上我有谁呢？除你以外，在地上我也没有所爱慕的。我的肉体和我的心肠衰残，但神是我心里的磐石，又是我的福分，直到永远。天堂连同它一切的福乐与荣美，若没有神，对敬虔人便是空虚死寂的；而当他活在与神的相交里，他就不再爱慕地上的任何一物，因为神的爱远远超越一切别的美物。

这是神儿女的经历，是他们亲身经历到的，因为神自己在他爱子里把自己赐给他们享受。所以基督也说，对于人，永生、全备的福乐，就在于认识那独一的真神，和认识他所差来的耶稣基督。

基督说这话时，正是一个庄严的时刻。他即将过汲沦溪，进入客西马尼园，在那里打他心灵最后的一仗。在此之前，他作为我们的大祭司，为自己的受苦受死作预备，并求父，叫父藉着并在他受苦之后荣耀他，好叫子也能在颁赐一切恩惠——就是他此刻正藉着顺服以至于死所要获取的恩惠——之中，再一次荣耀父。子如此祈求时，他别无所求，所求的无非是父自己的旨意与美意。父原已将治理凡有血气者的权柄赐给他，好叫他把永生赐给一切父所赐给他的人。而那永生别无所是，只在于认识那独一的真神，就在那位奉差遣者耶稣基督的面上认识他（约17:1-3）。

耶稣在这里所说的认识，显然带着一种全然独特的性质。它与人所能获取的一切别的知识，不是程度上的分别，乃是原则与本质上的分别。我们只要把这两类知识略作比较，这一点就清楚显明出来。耶稣这里所指的对神的认识，在来源与对象、在本质与果效上，都与对受造之物的认识不同。

首先，它在来源上就与之不同，因为它惟独归功于基督。一切别的知识，我们在某种意义上是靠自己的洞察与判断、靠自己的努力与探究获取的。但对那独一真神的认识，我们必须像孩子那样，让基督赐给我们。离了他，这认识在哪里都寻不着，在任何学术的学府里、在任何有名的哲人那里都寻不着。惟独基督认识父。他原在起初与神同在，卧在父的怀里，面对面地看见他。他自己就是神，是父荣耀所发的光辉，是父本体的真像，是父自己独生的、极其亲爱的儿子，父的一切美意都在他里面（太3:17；约1:14；罗8:12；来1:3）。在父的本质里，向着子没有一样是隐藏的，因为他与父同有一样的性情、一样的属性、一样的知识。除了子，没有人认识父（太11:27）。

而这位子已经到我们这里来，把父向我们讲明了。他把父的名向世人显明。他为此成了肉身、显现在地上，为要叫我们认识那位真实的（约壹5:20）。我们从前不认识神，甚至不喜爱认识他的道。但基督使我们认识了父。他不是哲人，不是科学家，不是艺术家；他的工作，是向我们启示父的名。这事他做了，做得完全，做了他一生之久。他在他的言语里、在他的作为里、在他的生里、在他的死里、在他的位格里、在他整个的显现里，把父启示了出来。他所说所行，无非是他看见父所做的。遵行父的旨意，就是他的食物。人看见了他，就是看见了父（约4:34；8:26,28；12:50；14:9）。

而他在这启示上是可信的，因为他就是那位耶稣、基督、奉差遣者。"耶稣"这名是他从神自己领受的，因他要将自己的百姓从罪恶里救出来（太1:21）。他称为"基督"，因他是父的受膏者，被神自己拣选、装备承担他一切的职任（赛42:1；太3:16）。他又是"奉差遣者"，因他不像那许多假先知、假祭司，是奉自己的名来的、是自立自封、自取那尊荣的；乃是因为父爱世人，甚至将他的独生子赐给他们，叫一切信他的，不至灭亡，反得永生（约3:16）。

因此，凡接待他的，就得着权柄与资格，可以称为神的儿女（约1:12）。他们是从神生的，他们与神的性情有份，他们在他儿子基督的面上认识神。除了父，没有人认识子；除了子和子所愿意指示的，没有人认识父（太11:27）。

其次，对神的认识在它的对象上，与一切别的知识不同。因为后者纵然——尤其在近来——扩展得如此之远，它所环绕的仍是受造之物，仍局限于有限，而寻不见那位无限者。诚然，在自然的作为里，也有一种对神永能与神性的启示。但由此得来的对神的认识，是微弱的、昏暗的、掺杂着谬误的，而且还不被人看重。因为世人虽然从自然认识神，却不当作神来荣耀他、感谢他，反倒在自己的思念上变为虚妄，将那不能朽坏之神的荣耀，变为受造之物形象的样式。世界既是神的一种遮蔽，也是神的一种启示（罗1:20-23）。

但在这里，在这大祭司的祷告中，有一位出现在我们面前，他撇下一切有限的，竟提说对神的认识！神作人认识的对象，谁能领会这事？神，那位无限者、不可测度者，是时间与永恒都量不透的；众天使在他面前用翅膀遮脸；他住在人不能靠近的光里，是人未曾看见、也不能看见的！他，竟作人认识的对象——作那鼻孔里只有气息、比虚无更虚无、比虚空更虚空之人认识的对象！他，这一切所知不过是零星片段的人，竟要认识神！他纵有一切所知，又认识什么呢？论到自己的来源、自己的本质、自己的归宿，他认识什么呢？奥秘岂不是从四面把他围住？他岂不是屡屡站在那未知之境的边缘？而这样一个人——一个贫乏、软弱、迷失、昏暗的受造之物——竟要认识神，那至高、至圣、独一全智、全能的神！

这远超我们的悟性，然而基督提说这事，他是看见过父、又将父向我们讲明的那一位。我们可以信靠他，他的见证是信实的，是十分可佩服的。人哪，你若想知道神是谁，不要去问智慧人，不要去问文士，不要去问这世代的探究者，只要仰望基督、听从他的话！不要心里说：谁要升到天上去呢？谁要下到深渊去呢？因为那话与你相近，就是基督向你所传的话。他自己就是那道，是父完全的启示。他怎样，父也怎样，一样公义、一样圣洁，也一样满有恩典和真理。在他的十字架旁，旧约信仰的全部内涵舒展开来：耶和华有怜悯，有恩典，不轻易发怒，且有丰盛的慈爱。他没有按我们的罪过待我们，也没有照我们的罪孽报应我们。因为天离地何等的高，他的慈爱向敬畏他的人也是何等的大。东离西有多远，他叫我们的过犯离我们也有多远。父亲怎样怜恤他的儿女，耶和华也怎样怜恤敬畏他的人（诗103:8-13）。当我们在他话语的镜中观看基督的荣耀，就欢欣鼓舞地呼喊：我们认识他，因为我们先被他认识；我们爱他，因为他先爱我们（约壹4:19）。

第三，藉着来源与内容，对神之认识的本质也在它的独特之处上被界定出来。

在方才所引大祭司祷告的那节经文里，耶稣所说的，不是一种"知道"神，乃是一种"认识"神。二者之间的分别甚大。从书本上知道许多关于某个受造物——某株植物、某只走兽、某个人、某个地方或某个民族——的事，与从自己亲身的观看来认识它，是全然两样的。"知道"针对的是别人对某人或某事所作的描述；"认识"针对的是那对象本身。"知道"是头脑的事，"认识"却含有一种亲身的关切和一种心的运作。

因为基督所赐下的、对神的那认识，在他的话语里可以找到一段描述，所以在这领域里有一种"知道"是可能的，它与耶稣所指的那"认识"在本质上有别。有一种对主旨意的知道，却没有一颗甘心遵行那旨意的心（路12:47-48）。有一种呼喊"主啊，主啊"，却绝不能开启进天国的门（太7:21）。有一种信，如同鬼魔的信，激起的不是爱，乃是惊惧战兢（雅2:19）。有一等听道的人，不肯作行道的人，因此要被加倍地责打（雅1:23）。

耶稣在这里说到认识神，他所着眼的，是一种与他自己所拥有的相近的认识。他不是职业的神学家，不是神学的博士或教授。但他藉自己的观看认识神；他在各处看见他，在自然里、在他的话里、在事奉他之中；他爱他胜过一切，凡事顺服他，直到死在十字架上。他对真理的认识，与对真理的实行是合一的；而这认识与爱融为一体。

耶稣把生命与认识相连时，他所指的正是这样一种认识。不，认识神，不在于知道许多关于神的事，乃在乎我们在基督的面上亲眼见过他自己，我们在人生路上与他相遇过，并在我们心灵的经历里亲身领略过他的美德、他的公义与圣洁、他的怜悯与恩典。

因此，为要与别的学问相区别，这认识被称为"信心的认识"。它不是理性探究与思辨的果子，乃是那孩童般单纯之信心的果子——就是那不单是一种确实的知道、也是一种坚定的信靠的信心：确信不单是别人，也是我，白白地、单单因基督的功劳，从神领受了罪的赦免、永远的公义和救恩。惟有变成小孩子样式的人，才能进天国（太18:3）。惟有清心的人，才能得见神的面（太5:8）。惟有从水和圣灵重生的人，才能见神的国（约3:5）。人若立志遵着神的旨意行，就必晓得基督的教训或是出于神，或是他凭着自己说的（约7:17）。认识他名的人要倚靠他（诗9:10）；而神被认识的程度，正与他被爱的程度相等。

我们若这样领会对神的认识，那么第四，也就不足为奇：它的功效与果子不亚于永生本身。在知识与生命之间，似乎极少有什么关联。传道者岂不是照实说：多有智慧，就多有愁烦；加增知识的，就加增忧伤；著书多，没有穷尽；读书多，身体疲倦（传1:18；12:12）。

知识就是力量——这一点我们至少在某种程度上懂得。谁认识，谁就掌权。一切认识都是心智对物质的一次得胜，是地被降服于人之治理的一次实现。但知识就是生命——谁明白这个呢？然而，即使在自然的层面，随着知识的增长，生命的深度与丰盛也随之增加。意识越是广阔，生命就越是浓密。无灵的受造物不认识，也不活。当知觉在走兽里苏醒，它们的生命也在内涵与广度上有所增益。在众人之中，认识最多的人，生命最为丰富。心思有病的人、愚昧人、单纯人、未受开化之人的生命，何等贫乏狭隘，与思想家、诗人的生命相比！但这里无论有多大的差别，也不过是程度的差别，生命本身并不因此改变；无论是最伟大的学者，还是最单纯的雇工，那生命终归都要沉入死亡，因为它只从这世界那有限的源头得着供养。

但这里所说的认识，不是关乎任何受造之物，乃是关乎那独一的真神。

若对可见之物的认识尚且丰富生命，那么对神的认识岂不更要成为那从死里得来的生命么？神原不是死人的神、死亡的神，乃是活人的神、生命的神。一切被他照自己形象重造、被他恢复到与他相交里的人，都因此被高举，超乎死亡与朽坏之上。耶稣说，信我的人，虽然死了，也必复活；凡活着信我的人，必永远不死（约11:25-26）。在基督的面上认识神，带来永生、无扰的喜乐、属天的福乐。它不单以此为其后果，乃是——认识神，当下自身就是生命，是新的、永远的、有福的生命。

按照圣经这样的教导，基督教会里那门自古被称为"神学"（Theologie，认识神之学）的学问，其性质也被如此界定。它是这样一门学问：从神的启示引出对神的认识，在他圣灵的引导下加以思索，然后力求为荣耀他而将它表述出来。一个神学家，一个真正认识神的人，就是那从神、藉神、论到神，为荣耀他的名而说话的人。因此，在学者与单纯人之间，只有程度的分别。他们同有一主、一信、一洗、一神，就是众人的父，超乎众人之上，贯乎众人之中，也住在众人之内。然而，照着基督所量给各人的恩赐，这恩典是分给我们各人的（弗4:5-7）。

本着这样的精神，加尔文以这样一个问题作为他《日内瓦要理问答》的开端：人生首要的目的是什么？答案清晰而有力：是要叫人认识那创造他们的神。同样地，《西敏要理问答》也以这样一个问题开始它的教导：人首要、至高的目的是什么？并给出这简短而意味深长的回答：人首要的目的，是荣耀神，并永远完全地以他为乐。
